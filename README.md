# Practical Statistics for Data Scientists

This repository contains my code reproduction and notes from the book **Practical Statistics for Data Scientists (O'Reilly)**.

The purpose of this repository is to help me understand the statistical concepts used in data science by practicing the code and writing short explanations for each topic.

## Chapters

### Chapter 1 - Exploratory Data Analysis
This chapter introduces basic methods for understanding data before further analysis. It covers data types, measures of location and variability, data distributions, correlation, and several visualization techniques.

### Chapter 2 - Data and Sampling Distributions
This chapter discusses random sampling, sampling distributions, bootstrap, confidence intervals, and several probability distributions commonly used in statistics and data science.

### Chapter 3 - Statistical Experiments and Significance Testing
This chapter focuses on statistical experiments and hypothesis testing. Topics include A/B testing, permutation tests, p-values, t-tests, ANOVA, chi-square tests, and statistical power.

### Chapter 4 - Regression and Prediction
This chapter explains regression for understanding relationships between variables and making predictions. It covers simple and multiple linear regression, model evaluation, categorical variables, regression diagnostics, and nonlinear methods such as polynomial regression and splines.

### Chapter 5 - Classification
This chapter covers methods for predicting categorical outcomes. It includes Naive Bayes, Linear Discriminant Analysis, Logistic Regression, classification evaluation metrics, ROC curves, AUC, and strategies for imbalanced data.

### Chapter 6 - Statistical Machine Learning
This chapter introduces machine learning methods such as K-Nearest Neighbors, Decision Trees, Random Forest, and Boosting. It also discusses standardization, feature importance, overfitting, regularization, and hyperparameter selection.

### Chapter 7 - Unsupervised Learning
This chapter introduces methods for discovering patterns in data without using a known target variable. It covers Principal Components Analysis, K-Means Clustering, Hierarchical Clustering, Model-Based Clustering, and the importance of scaling variables.
