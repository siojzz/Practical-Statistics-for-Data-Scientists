# Practical Statistics for Data Scientists

This repository contains my code reproduction and notes from the book **Practical Statistics for Data Scientists (O'Reilly)**.

The purpose of this repository is to help me understand the statistical concepts used in data science by practicing the code and writing short explanations for each topic.

## Chapters

- Chapter 1 - Exploratory Data Analysis
- Chapter 2 - Data and Sampling Distributions
- Chapter 3 - Statistical Experiments and Significance Testing
- Chapter 4 - Regression and Prediction

## Tools

- Python
- Jupyter Notebook / Google Colab
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
